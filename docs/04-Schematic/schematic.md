## Overview

This schematic is designed to receive and display various weather data from three sensor boards. The PIC18F57Q43 Curiosity Nano communicates with the LCD, cycling through readings with the push of a button. To accomplish this, the design features 5 V and 3.3 V regulators, each supporting a subsystem and ensuring a high-quality user experience.
